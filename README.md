# Timeti para Android

O **Timeti** é um jogo de cartas educativo: duas cartas quaisquer têm sempre exatamente um desenho em comum, e quem acha primeiro ganha o ponto. O jogo exercita o Pensamento Computacional e traz temas de STEAM e da cultura brasileira.

Criado por **Juliana Pereira de Magalhães** no seu Trabalho de Conclusão de Curso em Ciência da Computação na Universidade Federal do Amazonas (UFAM), com orientação da **Profa. Dra. Rosiane de Freitas**, no grupo Algox / Jogos Inteligentes do Instituto de Computação (IComp).

Este repositório guarda só as versões do app para testes.

## Baixar

**[Baixar a versão mais recente (timeti.apk)](https://github.com/Lucased22/timeti-releases/releases/latest/download/timeti.apk)**

Ou aponte a câmera do celular para o QR code:

![QR code para baixar o Timeti](qrcode-baixar-timeti.png)

As versões anteriores e as novidades de cada uma estão em [Releases](https://github.com/Lucased22/timeti-releases/releases).

## Como instalar

1. Abra o link ou o QR code no celular Android (Android 8 ou mais novo).
2. Abra o arquivo `timeti.apk` baixado.
3. Se o Android pedir, permita que o navegador ou o gerenciador de arquivos **instale apps desconhecidos**.
4. Se o Play Protect avisar que o app é desconhecido, toque em **Instalar mesmo assim**. O aviso aparece porque o app ainda não está na Play Store.

## Atualizar

Baixe de novo pelo mesmo link ou QR code e instale por cima. Seus dados continuam no app. A versão instalada aparece na tela **Sobre**.
